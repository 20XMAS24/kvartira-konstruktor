# 3D-сцена: модели, правка, прогулка, свет, шейдеры

## Библиотека

Three.js r147: последняя удобная ветка с глобальной сборкой и `examples/js`. Возьми из пакета `three@0.147.0` файлы `build/three.min.js`, `examples/js/loaders/GLTFLoader.js`, `examples/js/environments/RoomEnvironment.js` и положи в `vendor/` вместе с лицензией.

## Модели и текстуры

- Для публичного репозитория бери только CC0. Poly Haven подходит: есть открытый API, а лицензию не нужно отслеживать по каждому файлу. Список источников положи в `assets/README.md`.
- Скачать: `scripts/fetch_polyhaven.py`. Сначала посмотри список: `--list furniture`.
- Сжать: `npx @gltf-transform/cli optimize in.gltf out.glb --compress false --instance false --texture-compress webp --texture-size 512 --simplify false`. Так 11 моделей занимают около 4 МБ.
- Смотри каждую текстуру глазами до подключения. По названию не угадать: `marble_tiles` оказался грязной мозаикой, `plank_flooring_03` старыми досками, `floor_tiles_06` тёмной шашкой, а `Shelf_01` выглядит как бетонный блок.
- Современных кухонных модулей, кроватей, холодильников и сантехники в библиотеке почти нет. Собирай их из деталей: цоколь, фасады, ручки, столешница, эмаль, сталь. Человеку скажи об этом прямо.

## Вписывание модели в предмет

1. Система предмета: центр в нуле, спинка при `-z`, фасад при `+z`, `y` вверх. Поворот на плане по часовой переводится как `rotation.y = -rot`.
2. Измерь `Box3` шаблона, сдвинь к нулю, масштабируй под `w`, `h`, `d`. Так размеры из свойств работают и для моделей.
3. **Собери тестовый стенд:** все модели в ряд с поворотом 0, камера спереди. Иначе не заметишь модель, стоящую спиной. Загрузка JSON с таким рядом заодно проверит импорт.
4. Клонированным мешам ставь `userData.shared`, чтобы не освобождать общую геометрию при пересборке.

## Цвет и материалы

- Текстуры часто темнее, чем кажется: умножение на цвет только затемняет, белая кухня становится чёрной. Светлую отделку делай без текстуры, крашеной. Ткань и светлые модели закрашивай целиком, снимая `map` и сохраняя карту нормалей.
- Значения цвета больше 1 работают в шейдере: `color.multiplyScalar(2)`. Так ламинат можно осветлить без правки файла. Чтобы убрать оранжевый оттенок, умножай сильнее по синему каналу, например цвет `0xa6d9ff` с усилением 2,2.
- `RoomEnvironment` даёт слишком много света, цвета выцветают. Ставь `envMapIntensity` около 0,4 всем материалам, включая загруженные.
- Столешница с текстурой на коробке получает растянутый узор. Лучше ровный материал с низкой шероховатостью.
- Пол: `ShapeGeometry`, вершины переложены в плоскость XZ, UV в сантиметрах, порядок индексов перевёрнут, нормаль вверх. `texture.repeat = 1 / размер_плитки_в_см`.

## Обновление сцены

Пересобирай предмет, только когда меняется подпись `cat|kind|role|w|d|h|color|тема|модель загружена`. Положение и поворот меняй напрямую: иначе перетаскивание подвисает. Рендер по запросу, цикл только на прогулке. `shadowMap.autoUpdate = false`, а `needsUpdate` при изменении сцены, но не при движении камеры.

## Правка мышью

- Выбор: луч по предметам и видимым стенам, ближайшее попадание. Стена закрывает предмет за собой.
- Перетаскивание: пересечение луча с горизонтальной плоскостью на высоте точки захвата, смещение от центра запоминается. Дальше та же функция привязки, что на плане, чтобы логика была одна.
- Панель над предметом через проекцию точки на экран: поворот, высота (перетаскивание по вертикали), копия, удаление.
- Вид сверху: прячь стены между камерой и центром вида. Считай от `orbit.target` и размера показанной области, иначе при показе одной комнаты её заслоняют соседние.

## Прогулка

- Камера с порядком осей `YXZ`, глаза на 160 см, поле зрения около 68°. На выходе вернуть настройки.
- Клавиши по `e.code`: иначе не работает русская раскладка. Перехватывай их на фазе захвата, чтобы `R` и `Delete` не правили мебель.
- Столкновения: тело-круг радиусом 18 см, проверка отдельно по осям, тогда человек скользит вдоль стены. Шкафы ниже 180 см преграда, выше нет. Функция лежит в `geo.js` и покрыта тестами.
- Захват мыши по клику, запасной вариант перетаскивание. Захват может быть запрещён, а вызов возвращать промис с ошибкой.
- На прогулке включай потолок: он даёт тень, поэтому солнце идёт только через окна. Для этого опускай солнце ниже.
- Сенсорные кнопки показывай через `@media (pointer: coarse)`.

## Свет

- Режимы день, вечер, ночь задают солнце, долю окружения, экспозицию, цвета неба, силу ламп.
- Потолочный `PointLight` на помещение с тенью 512 px. Без тени свет проходит сквозь стены.
- Для светильников из каталога заранее создай пул из 6 источников с нулевой силой. Число источников не меняется, поэтому шейдеры не пересобираются при добавлении лампы.

## Шейдеры

- **Небо:** сфера с `ShaderMaterial`, градиент верх, горизонт, низ.
- **Постобработка:** рендер в цель `HalfFloatType` с MSAA, отдельный проход глубины без сглаживания с `DepthTexture`, затем полноэкранный проход.
- В полноэкранном шейдере: затенение углов по глубине (14 точек на диске, радиус в сантиметрах, проверка диапазона, чтобы не было ореолов), экспозиция, ACES, насыщенность, виньетка, гамма. При рендере в цель Three.js не применяет тональную кривую и sRGB, поэтому они нужны здесь.
- Дай галочку отключения: это самая дорогая часть для слабых устройств.

## Ограничения

С `file://` браузер не отдаёт текстуры в WebGL, а `fetch` моделей не работает. Определи это по `location.protocol`, покажи упрощённые материалы и объясни в подсказке.
