# Проверка и публикация

## Что проверить перед отправкой

Логику проверяют тесты: `node --test tests/`. Интерфейс проверяй настоящими действиями в браузере и смотри скриншоты.

- Перетаскивание из каталога на план и в 3D, столкновение, отмена.
- Каждый вид: план, стены, 3D. Каждый дизайн, вблизи и издалека.
- Экспорт PNG, JSON и CSV: перехвати `URL.createObjectURL` и `a.click` и посмотри размеры файлов. Клик по кнопке ничего не доказывает.
- Импорт JSON: подставь файл в `input` через `DataTransfer`.
- Телефонная ширина: нет горизонтальной прокрутки.
- Консоль без ошибок. Разовый сброс соединения у `python -m http.server` при перезагрузке не баг, повторный запрос проходит.

## Ошибки, которые уже случались

| Симптом | Причина | Что делать |
|---|---|---|
| PNG молча не создаётся | Повтор атрибута в SVG: HTML это прощает, строгий SVG как картинка нет | Тест на повторы атрибутов всей разметки, `img.onerror` с сообщением |
| Панель браузера показывает страницу без скриптов | Файл открыт как статичный снимок | Запускай через локальный сервер |
| Изменения не видны | Браузер держит старые JS | `fetch(url, { cache: 'reload' })` и перезагрузка; человеку `Cmd+Shift+R` |
| После правки тест «без замечаний» падает | Новый предмет реально мешает | Сдвинь предмет, а правило не ослабляй |
| Шаг на прогулке короткий | Человек упёрся в мебель | Смотри, что стоит рядом, прежде чем искать ошибку скорости |

## GitHub

Перед отправкой спроси подтверждение, если человек не просил об этом именно сейчас: разрешение на прошлую отправку не распространяется на новую работу. Перед коммитом проверь, что личные файлы не попали в индекс.

- Чужие учётные данные не извлекай. Не запрашивай их через `git credential fill` и не ищи токены. Для `git push` достаточно обычной настройки git.
- Если `gh` нет, пустой репозиторий создаётся на `github.com/new` в браузере. Вход выполняет сам человек. Пока он вводит логин, не трогай страницу.
- В форме репозитория не включай README, `.gitignore` и лицензию: иначе первая отправка конфликтует с локальной историей.
- Формы GitHub меняются, а кнопка после загрузки сдвигается. Делай новый скриншот перед кликом и проверяй результат.

## GitHub Pages

Включается в Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Работает на публичном репозитории бесплатно.

**Успешный `push` не означает обновление сайта.** Проверяй так:

```bash
curl -s "https://api.github.com/repos/OWNER/REPO/actions/runs?per_page=3" \
  | python3 -c "import json,sys;[print(r['head_sha'][:7],r['status'],r['conclusion']) for r in json.load(sys.stdin)['workflow_runs']]"
```

Затем запроси на сайте файл, который появился только в новой версии, и открой сайт в браузере.

Публикация может зависнуть, и следующая тогда падает с ошибкой `due to in progress deployment`. Код тут ни при чём. Лечится повторным запуском на странице Actions или новым `push`, который запустит сборку заново. Если ты уже сказал человеку, что сайт обновлён, а это не так, исправь свои слова прямо.
