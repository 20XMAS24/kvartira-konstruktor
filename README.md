# Конструктор квартиры

Планировщик однокомнатной квартиры в браузере: план в масштабе, каталог мебели и техники, развёртки стен, 3D и проверки расстановки. Без сборки и зависимостей, работает офлайн.

## Запуск

Откройте `index.html` в браузере. Если браузер что-то блокирует, запустите локальный сервер:

```bash
python3 -m http.server 4178
```

и зайдите на http://localhost:4178.

## Что умеет

- **План.** Все пять помещений в масштабе, двери с зоной открывания, окна, батарея, шахты, розетки с высотами.
- **Каталог.** Около 70 предметов: кухонные модули, техника, мебель для комнаты и прихожей, сантехника, балкон, свои розетки.
- **Расстановка.** Перетаскивание, привязка к стенам и соседям, сетка 5 см, поворот на 90°, копирование, правка размеров, отмена.
- **Стены.** Вид на стену изнутри: шкафы, проёмы, высоты и положение розеток, линия столешницы.
- **3D.** Вращение, масштаб и ползунок высоты стен, чтобы заглянуть внутрь.
- **Смета.** Список по комнатам, цены, выгрузка в CSV.
- **Файлы.** Раскладка в JSON, картинка PNG. Текущая раскладка сохраняется в браузере сама.

## Что проверяется

| Проверка | Уровень |
|---|---|
| Предмет выходит за стены или выше потолка | ошибка |
| Предметы пересекаются (верхний шкаф над нижним не считается) | ошибка |
| Предмет стоит на батарее, в шахте или перед балконной дверью | ошибка |
| Путь от входной двери до комнаты перекрыт (нужно 40 см на плечи) | ошибка |
| Проход перед фасадом меньше нормы | замечание |
| Предмет мешает открыть дверь | замечание |
| Розетка закрыта, низко над столешницей, близко к плите или мойке | замечание |
| Плита дальше 60 см от силовой розетки, техника без розетки рядом | замечание |
| Низкая розетка за шкафом: нужен вырез в задней стенке | подсказка |

Нормы прохода настраиваются по комнатам. По умолчанию: кухня 90, комната и прихожая 70, санузел 60, балкон 50 см.

Расстояния до плиты и мойки в проверках — ориентиры для планирования, а не нормы электромонтажа. Точки подключения согласуйте с электриком.

## Откуда размеры

Все размеры лежат в [`js/apartment.js`](js/apartment.js), у каждого элемента указан источник.

- **По замерам:** кухня, её розетки, батарея, дверь и ширина балконного блока.
- **По плану, уточнить:** остальные помещения, их двери и окно, шахты, ниша в прихожей. Основные длины подписаны на плане, а положение дверей, шахт и окон снято с фотографии по масштабу, погрешность около 5–10 см.
- **Принято условно:** высота подоконников, верх окон и дверей, потолок 254 см вне кухни, толщина стен.

Площадь прихожей на экране 6,9 м² считается вместе с нишей, на плане указано 6,5 м².

## Устройство

```text
index.html         разметка
css/styles.css     оформление
js/apartment.js    геометрия квартиры
js/catalog.js      каталог предметов
js/presets.js      готовые раскладки
js/geo.js          геометрия и проверки, без DOM
js/draw.js         SVG плана и развёрток
js/view3d.js       3D-вид
js/app.js          состояние и интерфейс
vendor/            three.js r147 (MIT)
tests/             тесты
```

Тесты:

```bash
node --test tests/
```
